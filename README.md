# Memory Game

Игра на поиск пар: открывай карточки, запоминай их расположение и найди все 8 пар за наименьшее число ходов.

**Деплой:** https://xdobriev.github.io/memory-game/

**Задание:** [RS School — Memory Game](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

## Правила

- На поле 16 карточек — 8 пар одинаковых изображений. При загрузке страницы и каждой новой игре они перемешиваются.
- За ход открываются две карточки. Совпавшая пара остаётся открытой, несовпавшая закрывается через секунду.
- Пока несовпавшая пара открыта, другие карточки выбрать нельзя.
- Когда найдены все пары, открывается окно победы с количеством ходов, а результат попадает в таблицу лидеров.
- Таблица лидеров хранит 10 лучших результатов в `localStorage`: меньше ходов — выше место, при равенстве выше более ранняя игра.

## Возможности

- Вся разметка создаётся из JavaScript через `document.createElement` — в `<body>` файла `index.html` только `<script>`.
- Общий компонент модального окна для окна победы и таблицы лидеров: закрытие кнопкой, кликом по фону или клавишей Escape, блокировка прокрутки и элементов страницы под окном.
- Адаптивная вёрстка от 320px, анимация переворота карточек (отключается при `prefers-reduced-motion`).
- Изображения карточек — собственные SVG.

## Стек

HTML, CSS, JavaScript (ES-модули), без фреймворков и библиотек. Для разработки — ESLint и Prettier.

## Структура

```
index.html
assets/images/           изображения карточек (SVG)
src/css/style.css        стили
src/js/
  main.js                точка входа: собирает приложение
  game.js                состояние и логика игры
  leaderboard.js         сохранение и чтение результатов
  data/cards.js          набор изображений карточек
  components/            хедер, счётчики, поле, модальные окна
  utils/                 обёртка над createElement, перемешивание, склонения
```

## Локальный запуск

ES-модули не работают при открытии файла напрямую (`file://`), поэтому нужен локальный сервер.

1. Клонируйте репозиторий и перейдите в ветку `memory-game`:

   ```bash
   git clone https://github.com/XDobriev/memory-game.git
   cd memory-game
   git checkout memory-game
   ```

2. Запустите сервер (нужен [Node.js](https://nodejs.org/)):

   ```bash
   npm start
   ```

   Игра откроется по адресу http://localhost:8080.

   Другой вариант — открыть папку в VS Code и запустить `index.html` через расширение Live Server.
